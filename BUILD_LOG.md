Unparsed output isn't acked, so the Rust ack window holds the programs back. Timers, not frames, so hidden panes keep draining. The perf suite runs a `--profile perf` binary (release with debug assertions).

Panes shown together tie and keep the contexts they hold, so a mode switch back to 16 panes attaches nothing (it used to evict and re-attach 8 contexts synchronously: 1.2 s). "GPU rendering: Off" never applied: the setting stores `"off"` and the view compared with `false`; it now resets the pool.

The cell is measured again only when the web font was still loading at open — a re-measure costs a full re-render (200–300 ms) and every new pane did one, twice. A font face that loads later (bold, italic) clears the WebGL glyph atlas instead.
