# Tandem: rules for coding agents

## Always
- Read `BUILD_LOG.md` ("Current state") before working. Update it after every slice.
- Read `docs/OPERATING.md` for machine setup, commands, E2E lessons, releasing, deploying and checking the live site.
- Follow `build-kit/DECISIONS.md`. The stack, names and layout are fixed.
- Write tests from the acceptance criteria (`F-AREA-nn`) before implementing, and reference the ID in test names.
- Run the global gate G (`pnpm gate`, DECISIONS rule 1) before every commit:
  ```bash
  pnpm -r lint && pnpm -r test && cargo test --workspace && pnpm --filter desktop build
  cargo clippy --workspace --all-targets -- -D warnings && cargo fmt --all --check
  bash scripts/windows-check.sh --clippy   # cfg(windows) code, x86_64-pc-windows-gnu
  pnpm gen:protocol && git diff --exit-code packages/protocol
  ```
- Make small commits: `M<n>: F-XX-nn <what>`.

## Never
- Use names, branding, copy or code from other products (including anything under `build-kit/reference/`).
- Store secrets anywhere but the OS keychain (`keyring` crate). Log tokens, prompt text or file contents.
- Send data off the machine without an explicit user opt-in (telemetry, Auto scrollback, cloud STT).
- Read, copy or proxy AI-vendor OAuth tokens. Engines authenticate themselves inside their own provider home.
- Skip, delete or weaken a failing test to go green. Fix the cause.
- Block on a human. Stub it behind an interface, add it to `HUMAN_TODO.md`, and continue.

## Conventions
- **Rust:** edition 2021, `thiserror` for library errors, `anyhow` only in binaries, `tracing` for logs, no `unwrap()` outside tests. `cargo clippy -D warnings` and `cargo fmt`.
- **TypeScript:** strict mode, no `any`, ESLint + Prettier. Shared types come from `packages/protocol` (generated by `ts-rs`, never hand-edited).
- **IPC:** every Tauri command and event is declared in ARCHITECTURE.md. Add new ones there first.
- **UI:** use only `packages/ui` components and tokens. No ad-hoc colours or spacing. Every screen has empty, loading, error and populated states.
- **Platform code** goes behind `cfg(target_os)` modules with a shared trait. Each implementation is unit-tested with fakes.
- **Paths:**
  - App data: `~/.tandem/` (overridable with `TANDEM_HOME`, which tests must set to a temp dir).
  - Provider homes: `~/.tandem/providers/<engine>/<account>/`.
  - Worktrees: `<repo>/.tandem/worktrees/<slug>`, on branches `tandem/<slug>`.
