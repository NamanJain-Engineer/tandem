# remote-web

The phone web app that LAN mode serves at `http://<lan-ip>:<port>/remote`
(F-RM-04). It's built here by `sh scripts/build-remote-web.sh` (the release
scripts run it) from `apps/web/remote-lan`, and isn't committed. Without it,
LAN mode still pairs the Vibezeo Remote app; the page just says to use the app.
