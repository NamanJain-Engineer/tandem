> **Not in the app yet.** Agent mode isn't in the current release. This page describes what is being built (M10 in the build plan), and it will be filled in when it ships. [The changelog](/changelog/) says what each release contains.

Agent mode gives you persistent teammates: each has a brief, memory, skills and its own chats, learns after a turn, can search past sessions and can mail other teammates, all through one local gateway.
