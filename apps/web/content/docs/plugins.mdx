> **Not in the app yet.** Plugins and approvals isn't in the current release. This page describes what is being built (M12 in the build plan), and it will be filled in when it ships. [The changelog](/changelog/) says what each release contains.

Plugins connect external services once and grant them to a teammate or thread. Every action has a risk class: some run, some ask you first, and some are held as drafts for you to review. Engines never see a plugin's token.
