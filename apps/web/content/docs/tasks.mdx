title: Tasks
description: A local task tracker your agents read and write.
---

Tasks is a task tracker stored on your computer, in the app's data folder. Open it from the sidebar's **Tasks** tab, from **Tasks** at the foot of Agent mode's rail, or with **Open Tasks** in the command palette.

- **Tasks** have an ID (TAN-1, TAN-2…), a title, a description, a status (Backlog, To do, In progress, In review, Done or Canceled), a priority, labels, an assignee and a project, with threaded comments and a history of every change.
- **Quick add** puts a task in To do. The list groups tasks by status. Archive a task with its ×, and bring it back from **Show archived**.
- **Edits from anyone show up at once.** When an agent or another window changes a task you're editing, its other fields update and your unsaved text stays. If they changed the same field, Vibezeo says so and you choose **Keep mine** or **Take theirs**.

## Agents

Agents in your threads and teammate chats read and update the same tasks through Vibezeo's tasks server, and so do Claude Code and Codex in terminal panes. Every change lands in the task's history with who made it, so you can see what an agent did. Threads on an SSH host or in WSL don't get the tasks server: it runs on this computer.

## Plans

Tracking tasks and running them are both free, with no account. **Execute…** on a task runs it for you, in its own lane with progress posted as comments and an optional review, by a different engine when you have one.
