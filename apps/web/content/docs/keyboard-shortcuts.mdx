Mod is Command on a Mac and Ctrl on Windows and Linux. Every command is also in the command palette (<kbd>Mod+K</kbd>). This table is generated from the app's command registry, so it always matches the release. To change one, record new keys in **Settings › Shortcuts**: it tells you when a combination is already used, and refuses keys the system or text editing owns. <kbd>Mod+/</kbd> shows the shortcuts in effect.
