> **Not in the app yet.** Dictate isn't in the current release. This page describes what is being built (M8 in the build plan), and it will be filled in when it ships. [The changelog](/changelog/) says what each release contains.

Dictate turns speech into text in any app with a push-to-talk key, using speech models that run on your computer. Cloud speech-to-text, and Enhance and Polish for your prompts, are planned for Pro and use credits.
