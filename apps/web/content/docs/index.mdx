Vibezeo runs the coding agent CLIs you already use (Claude Code, Codex, Gemini CLI and others) side by side, in real terminals or as conversations, on your own subscriptions. The current release runs on Linux; see [Engines and platforms](/docs/engines/).

## Install

1. Download the `.deb` from the [download page](/download/) and check it against `SHA256SUMS` there.
2. Install it with `sudo apt install ./Vibezeo_<version>_amd64.deb`.

## First run

1. Have at least one coding agent CLI installed and signed in, the way you use it today. Vibezeo finds it on your login shell's `PATH` and never touches its sign-in.
2. Open the app and choose **Start**. The Free plan runs on your computer with no account.
3. Add a project folder. The launch grid lists the agents it found: pick one to start it in a terminal, or **Terminal** for a plain shell.
4. Split right with <kbd>Mod+D</kbd> (on Linux, <kbd>Ctrl+Shift+E</kbd> while a terminal has focus) and down with <kbd>Mod+Shift+D</kbd>, where Mod is ⌘ on a Mac and Ctrl elsewhere. <kbd>Mod+K</kbd> opens the command palette.

The Dashboard shows which agents are working and which are waiting for you. Every shortcut is listed in [Keyboard shortcuts](/docs/keyboard-shortcuts/); plan limits are in [Accounts and limits](/docs/accounts-and-limits/).
