---
title: Thread mode
description: Your engines as conversations, with approvals, plans and a Changes panel.
---

Thread mode runs an engine as a conversation instead of a terminal: replies stream in, tool calls fold away, and you can stop a turn or queue a follow-up.

- **Approvals** appear inline. Answer once, or for the whole thread.
- **Plan mode** keeps numbered plan versions; **Implement** runs the one you pick.
- **Changes** lists every file the thread changed since it started, and the files it read.
- **Turn summaries** close each turn that edited files or ran tests, such as "Changed 3 files +7 −4" and how many tests passed and failed. Codex and agents that speak ACP send each edit's diff. Claude Code doesn't, so its lines are counted from the edits it reports: a file it rewrites whole is named without line counts, and an edit that was refused or failed counts nothing.
- **Switching engines** mid-thread carries a summary of the conversation over.

## Engines

Threads run Claude Code, Codex, Cursor Agent, Gemini CLI, Grok, Kiro CLI, OpenCode and any agent you add that speaks ACP (Settings › Engines › ACP agents), and up to six show side by side. Every one runs with no account.
