---
title: Thread mode
description: Your engines as conversations, with approvals, plans and a Changes panel.
---

Thread mode runs an engine as a conversation instead of a terminal: replies stream in, tool calls fold away, and you can stop a turn or queue a follow-up.

- **Approvals** appear inline. Answer once, or for the whole thread.
- **Plan mode** keeps numbered plan versions; **Implement** runs the one you pick.
- **Changes** lists every file the thread changed since it started, and the files it read.
- **Switching engines** mid-thread carries a summary of the conversation over.

## Engines and plans

Threads run Claude Code, Codex, Cursor Agent, Grok and OpenCode, and up to six show side by side. Every one is free, with no account.
