---
title: Remote (SSH, WSL, phone)
description: Workspaces on SSH hosts and WSL distros, and a phone companion.
---

> **Not in the app yet.** Remote workspaces aren't in the current release. This page describes what is being built (M14 and M16 in the build plan), and it will be filled in when it ships.

- **SSH.** Terminals, agents, threads, files and git on an SSH host, through a small `tandem-host` helper that runs there. Host keys are checked, and local credentials are never forwarded.
- **WSL.** The same for WSL distros on Windows.
- **Phone.** A companion web app to see your agents and answer them from your phone, end-to-end encrypted, planned for Pro.
