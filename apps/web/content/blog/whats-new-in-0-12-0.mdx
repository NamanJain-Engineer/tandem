Vibezeo 0.12.0 is out for Linux, as a `.deb` for Debian and Ubuntu and an `.rpm` for Fedora. Vibezeo is free and needs no account, and like 0.11.0 it runs on your computer, with nothing sent to our servers.

0.11.0 was about running several agents at once and staying in charge of them. This release makes the app calmer to look at while they work, and lets a plan from Lead carry through from its first run to the landing.

## A new look

With several agents working side by side, the app should stay out of the way, and you should see at a glance which agent is which and which ones are working.

- **Quieter and sharper.** Neutral ink greys, tighter corners and softer shadows, in both the light and dark themes. A working agent shows a filled dot with a slow, breathing halo.
- **Engines are easy to tell apart.** Each engine has its own tinted letter tile in pane headers, the rail, the launch grid and threads.
- **Pane headers say where you are.** A pane's title names its engine and folder, tabs show the task in a few words, and the header's buttons stay quiet until you need them.
- **A calmer status bar.** It shows working agents, checks, usage and ports only while there's something to show.
- **Launch faster.** The launch grid takes number keys, marks the default engine, and copies an engine's command with one click.
- **Threads summarise their work.** A finished turn says which files it edited, with lines added and removed, and test runs show passed and failed counts.
- **A first-run page for Agents.** With no teammates yet, the Agents view helps you start one from a template.

## Follow a plan through

In 0.11.0, Plan with Lead split a goal into tasks and ran each one once in its own worktree. Once the runs started, you followed them task by task.

Now the plan lists each task with its latest run: queued, running, in review with the review's verdict (Approve or Changes requested), stopped, failed or done. A line counts them, and each row opens its task.

- **Land N approved…** opens Land worktrees with exactly the approved tasks' worktrees chosen, in the plan's order. You check the forecast and confirm the landing there.
- A plan stays in the Tasks page's header until you remove it, and comes back after a restart. Its chip there shows whether its runs are going, wait on you, or are done.
- If Vibezeo closed while Lead was planning, the plan says so and offers **Plan again**. If it closed while Execute all was starting the runs, or while Create tasks was writing, the plan keeps what was done, and the next try does only the rest.

## Chat threads claim the files they edit

In 0.11.0, Claude Code in a terminal pane claimed a file just by editing it. Now a Claude Code, Codex or ACP agent's edits in a chat thread claim their files too, so agents in other worktrees of the repository see the overlap. An edit you refused, or one that failed, claims nothing, and a task run is asked to claim its files before it edits them.

## Also in this release

- Freeze could fail with "Couldn't freeze this pane" on a pane running one short command after another, when a command ended just as Freeze stopped it. This happened only without a systemd user session. Freeze now keeps the pane's shell stopped instead, so the next command waits until you choose **Thaw**.

## Update or install

On Debian or Ubuntu, check the download against its checksum, then install it:

```bash
sha256sum Vibezeo_0.12.0_amd64.deb
sudo apt install ./Vibezeo_0.12.0_amd64.deb
```

On Fedora:

```bash
sha256sum Vibezeo-0.12.0-1.x86_64.rpm
sudo dnf install ./Vibezeo-0.12.0-1.x86_64.rpm
```

Compare each checksum with the one on the [download page](/download/). The full notes are in the [changelog](/changelog/0.12.0/).
