Local-first · early build

The desk where Claude Code actually works.

Vibezeo is a desktop workspace for people who already pay for Claude Code. It gives that CLI a real pane, a readable thread, and a named teammate. Your Claude login stays on your machine.

Panes

Claude Code runs in its own terminal, next to the other coding CLIs you choose. Each pane has its own working directory.

Threads

The same session can be read as a thread, so you are not stuck scrolling raw terminal output to see what changed.

Teammates

A teammate is a saved name, instructions, and engine. It is not a second model that we host or bill you for.

How Claude fits

Vibezeo hosts the Claude Code CLI. It does not replace Claude, and it does not read your Claude login. The engine signs in inside its own account folder. Prompts and files stay on the computer that has the repo.

  • Bring the Claude subscription you already have.
  • Vibezeo does not proxy Claude OAuth tokens.
  • Other CLIs can sit in other panes. Claude is not locked in, and it is not locked out.
